# A2ice / Театр «АБСУРД»

Локальный репозиторий для кастомного кода WordPress-сайта театра «АБСУРД» на Арбате.

## Назначение

Репозиторий хранит только безопасные для версионирования части проекта:

- `wp-content/themes/absurd-stage-v1` — активная кастомная тема.
- `wp-content/plugins/absurdtheater-core` — кастомный плагин проекта.

## Локальное окружение

- Локальный WordPress: `C:\OSP6\home\absurdtheater-wp.local\public`.
- Локальный URL: `http://127.0.0.1:8767/`.
- Активная тема: `absurd-stage-v1`.
- Активный плагин: `absurdtheater-core`.

## Правила безопасности

Не добавлять в репозиторий:

- ядро WordPress (`wp-admin`, `wp-includes`, корневые файлы WP);
- `wp-config.php`, `.env`, ключи, пароли и любые секреты;
- базу данных, SQL-дампы, логи, кэши и бэкапы;
- `wp-content/uploads` и пользовательские медиафайлы.

Перед коммитом проверять `git status --short` и добавлять только явно нужные файлы.
